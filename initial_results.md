# Initial Results and Demonstration

## Experimental setup

The reproducible baseline was run on the controlled fixture generated by the project:

| Setting | Value |
|---|---:|
| Sample rate | 16,000 Hz |
| Duration | 5.0 seconds |
| Input condition | Synthetic voiced-like signal with additive noise and synthetic room response |
| Target SNR setting | 5 dB |
| Target RT60 | 0.35 seconds |
| Frame / hop | 512 / 128 samples |
| Streaming chunk size | 256 samples |
| Dereverberation strength | 0.20 |

## Measured output

The values below are from the generated `artifacts/realtime_speech_enhancement_demo/evaluation.json` report.

| Metric | Degraded input | Enhanced output | Change |
|---|---:|---:|---:|
| SNR | 4.742 dB | 7.971 dB | +3.229 dB |
| SI-SDR | 4.829 dB | 7.817 dB | +2.987 dB |
| Real-time factor | - | 0.0262 | Below 1.0 in this run |
| Nominal algorithmic latency | - | 32 ms | 512 samples at 16 kHz |

The real-time factor is machine- and input-length-dependent. It is evidence for this run, not a hardware-independent performance claim.

## Reproduce the result

```powershell
python -m realtime_speech_enhancement demo `
  --out-dir artifacts/realtime_speech_enhancement_demo
```

The command produces:

- `clean_fixture.wav` — clean reference for the controlled experiment;
- `noisy_reverberant_fixture.wav` — degraded input;
- `enhanced_fixture.wav` — output from the streaming enhancer;
- `generation.json` — fixture configuration;
- `evaluation.json` — quality and timing measurements.

## Demonstration sequence

1. Play `noisy_reverberant_fixture.wav`.
2. Show the corresponding input waveform or spectrogram.
3. Run the enhancement command or replay `enhanced_fixture.wav`.
4. Show `evaluation.json` and explain SNR, SI-SDR, RTF, and nominal latency.
5. Repeat the procedure with a human-speech recording and a clean reference when available.
6. Add ASR WER only after selecting an ASR model and using the same aligned utterances before and after enhancement.

## Interpretation and limitation

The controlled result demonstrates that the implementation executes end to end and improves the chosen objective measures on this fixture. It does not establish general speech quality, speaker preservation, or ASR improvement. Those require the collected datasets and a documented human-speech evaluation split.
